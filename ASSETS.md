# Placeholder assets

All six projects are fictional. Their titles, descriptions, credits, and image paths live in `src/data/projects.ts`.

Every project image is currently an empty grey CSS box. There are no image downloads or artwork requests. Add a local image path to each `image` or gallery `src` field to replace a box; update alt text and dimensions to match the real image. The reusable renderer is `src/components/ProjectImage.tsx`.

Inter is self-hosted through Fontsource, under the SIL Open Font License. Only its Latin subset is loaded. `hello@example.com` is a reserved placeholder address; replace it in `src/components/Contact.tsx` before launch.
